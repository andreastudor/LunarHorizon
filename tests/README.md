# tests/

Teste comune părților aplicației: vectori de test pentru transformările de coordonate (folosiți identic în
Python și TypeScript), teren sintetic pentru algoritmul de orizont, teste de integrare și de interfață.
Testele unitare stau lângă codul pe care îl verifică, în `backend/` și `frontend/`.

Directorul este gol până la etapa E02. Lista testelor cerute, toleranțele și rezultatele sunt în
[docs/VALIDARE.md](../docs/VALIDARE.md); criteriile de acceptanță în [docs/ACCEPTANCE.md](../docs/ACCEPTANCE.md).

De reținut: datele sintetice au prefixul `synthetic_`; un test se consemnează ca trecut numai după rulare.
